# FK64v3 Vial-QMK Keyboard Firmware

This is a custom QMK / Vial firmware project for the **Blockboy FK64v3** 64-key mechanical keyboard.


---

## Hardware Specifications

| Attribute | Specification |
| :--- | :--- |
| **dev board** | STM32F103CBT6 bluepill |
| **Keyboard Layout** | Left-shift 64,compatible with Poker-60% cases. |
| **RGB LEDs** | 68 per-key LEDs (including 5 LEDs under the spacebar), 34 underglow LEDs |
